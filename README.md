# C1-3
노코드 제작도구 사용 - Make

# [특별전시회 참가자 이메일 발송] 자동화 설계 및 구현 보고서
Google Forms를 활용한 특별전시회 참석 여부 자동 관리 시스템
## 1. 프로젝트 개요
### 1.1 프로젝트명

Google Forms 기반 특별전시회 참석 여부 자동 관리 시스템

### 1.2 프로젝트 목적

행사 참여 신청을 받을 때 담당자는 신청자의 참석 여부를 확인한 후 엑셀 또는 Google Sheets에 직접 정리하고, 참석자와 불참석자에게 각각 다른 안내 메일을 발송해야 한다.

이러한 작업은 반복적으로 수행해야 하며 신청자가 많을수록 많은 시간이 소요되고 메일 발송 누락이나 오발송 등의 실수가 발생할 가능성이 있다.

본 프로젝트에서는 Make를 활용하여 신청 접수부터 데이터 저장, 참석 여부 분류, 안내 메일 발송까지 모든 과정을 자동화하여 업무 효율성을 향상시키는 것을 목표로 하였다.


## 2. 반복 업무 정의
자동화 대상 업무

[3.8 기념관 특별전시회] 참가 신청 관리

기존 업무 절차

Google Forms 신청서 제출 확인
신청 내용을 Google Sheets에 기록
참석 여부 확인
참석자와 불참석자를 구분
각각 다른 안내 메일 작성
Gmail을 이용하여 개별 발송

위 과정은 신청이 접수될 때마다 반복 수행되는 업무로 자동화가 필요한 업무이다.


## 3. 사용 도구
구분	사용 도구
자동화 플랫폼	Make
Trigger	Google Forms - Watch Responses
Action 1	Google Sheets - Add a Row
조건 분기	Router + Filter
Action 2	Gmail - Send an Email (참석자)
Action 3	Gmail - Send an Email (불참석자)


## 4. Make를 선택한 이유

이번 프로젝트에서는 Make를 자동화 도구로 선택하였다.

선정 이유는 다음과 같다.

Google Forms, Google Sheets, Gmail을 쉽게 연동할 수 있다.
시각적인 워크플로우 구성으로 전체 흐름을 이해하기 쉽다.
Router와 Filter를 활용하여 조건 분기를 쉽게 구현할 수 있다.
무료 플랜만으로도 프로젝트 구현이 가능하다.
실행 이력을 단계별로 확인할 수 있어 테스트 및 오류 수정이 편리하다.

## 6. 워크플로우 단계 설명
① Trigger
Google Forms - Watch Responses

사용자가 [3.8 기념관 특별전시회] 참가 신청서를 제출하면 Make가 새로운 응답을 감지하여 자동으로 워크플로우를 실행한다.

Trigger 역할

새로운 신청 감지
자동화 시작
② Router (조건 분기)

Google Forms에서 받은 응답 중 참석 여부를 기준으로 작업을 분기한다.

참석 선택

→ 참석자 경로 실행

불참석 선택

→ 불참석자 경로 실행

Router를 사용하여 하나의 Trigger에서 두 개의 작업 흐름을 구성하였다.

③ Filter

각 Router에는 Filter를 적용하여 조건을 설정하였다.

참석 신청자

조건

참석 여부 = 참석
불참석 신청자

조건

참석 여부 = 불참석

조건에 맞는 데이터만 다음 단계로 전달된다.

④ Google Sheets (Action)

신청자의 응답 내용을 Google Sheets에 자동 저장하였다.

저장 항목 예시

신청 시간
이름
이메일
참석 여부

Google Sheets를 활용하여 신청 내역을 실시간으로 관리할 수 있도록 구성하였다.

⑤ Gmail (Action)
참석자

참석으로 응답한 신청자에게 참석 안내 메일을 자동 발송하였다.

메일 내용 예시

신청 완료 안내
행사 일정
행사 장소
참석 감사 메시지
불참석자

불참석으로 응답한 신청자에게 신청 확인 메일을 자동 발송하였다.

메일 내용 예시

신청 확인
불참 접수 완료
향후 행사 안내


## 7. Trigger, Action, Filter 개념 설명
Trigger

자동화를 시작시키는 이벤트이다.

이번 프로젝트에서는

Google Forms에 새로운 응답이 등록되면 자동 실행된다.

Action

Trigger 이후 실제 수행되는 작업이다.

이번 프로젝트에서 사용한 Action은 다음과 같다.

Google Sheets에 데이터 저장
Gmail 참석 안내 메일 발송
Gmail 불참 안내 메일 발송
Router / Filter

조건에 따라 서로 다른 작업을 수행하도록 만드는 기능이다.

이번 프로젝트에서는

참석 → 참석자 메일 발송

불참석 → 불참석자 메일 발송

으로 자동 분기되도록 구성하였다.

## 12. 결론

이번 프로젝트에서는 Make를 활용하여 Google Forms, Google Sheets, Gmail을 연동한 자동화 시스템을 구현하였다.

사용자가 [3.8 기념관 특별전시회] 참가 신청서를 제출하면 Make가 새로운 응답을 감지하여 워크플로우를 실행한다. 이후 Router와 Filter를 이용해 참석과 불참석을 자동으로 분기하고, 신청 정보를 Google Sheets에 저장한 뒤 Gmail을 통해 상황에 맞는 안내 메일을 자동 발송하도록 구성하였다.

이를 통해 반복적인 수작업을 제거하고 신청 내역을 체계적으로 관리할 수 있었으며, 메일 발송의 정확성과 업무 효율성을 크게 향상시킬 수 있었다. 또한 Trigger, Action, Router(Filter)의 개념을 실제 자동화 시나리오에 적용해 봄으로써 노코드 자동화 도구의 활용 방법과 워크플로우 설계 과정을 이해할 수 있었다.
